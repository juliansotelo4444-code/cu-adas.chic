# 🌸 Cuñadas Chic — Sistema de Gestión de Fardos de Ropa Usada & Vintage

Aplicación web especializada para la administración integral del negocio **Cuñadas Chic**, enfocada en la venta de **fardos de ropa usada, ropa americana y prendas vintage**, con una estética femenina, intensa en tonos rosa y toques dorados metálicos.

---

## 🌟 Estado del Sistema
- **Base de Datos Limpia:** El sistema está listo para ingresar tus datos reales desde cero (sin datos de prueba).
- **Nombre del Negocio:** Personalizado para **Cuñadas Chic** en encabezados, tickets de compra y etiquetas.
- **Estética Femenina:** Paleta rosa chic y oro metálico.
- **Lenguaje Sencillo:** Todo redactado de forma cotidiana y fácil de usar.

---

## 🚀 Inicio Rápido

1. Haz doble clic sobre el archivo [iniciar_sistema.bat](file:///D:/Proyectos-web/Nueva%20carpeta%20%282%29/iniciar_sistema.bat).
2. O ejecuta en la terminal:
   ```powershell
   npm start
   ```
3. Tu navegador se abrirá automáticamente en:
   👉 **`http://localhost:3000`**

---

## 📋 Pantallas del Sistema

1. **🏠 Resumen:** Muestra de un vistazo lo que vendiste, tus ganancias limpias y la ropa lista para vender.
2. **📦 Mis Fardos:** Registra cada fardo anotando precio de compra, fletes, aduanas y lavado para calcular el costo por prenda. Incluye el botón **"Cargar ropa de este fardo"**.
3. **👗 Mi Ropa:** Control de cada prenda con su código, talle, color, estado y botón para imprimir etiquetas para colgar en la ropa con código de barras.
4. **🛍️ Cobrar / Vender:** Mostrador rápido para elegir la ropa que se llevan, anotar a la clienta, si te dejó una seña o pagó todo, y generar el ticket.
5. **🧾 Ventas Hechas:** Registro de todas tus ventas y botón para reimprimir el ticket de compra.
6. **👥 Mis Clientas:** Directorio con enlace directo a WhatsApp, usuario de Instagram y aviso de señas pendientes.
